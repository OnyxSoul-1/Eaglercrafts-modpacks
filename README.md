# ⛧ Eaglercrafts-Modpacks

A collection of **6 standalone Eaglercraft modpacks** compiled entirely as single HTML files. No installation, server setups, or extra software required—just open an HTML file in your web browser and start playing fully modded environments instantly.

## 🚀 Features

- 📄 **HTML-Only Architecture:** Every single modpack is self-contained within a single `.html` file. 
- 🌐 **True Offline Play:** Download the HTML file to your local computer or Chromebook and play entirely without an internet connection.
- 🎒 **6 Unique Pre-Built Packs:** A curated selection of 6 distinct gameplay environments optimized for browser performance.

## 📁 Repository Structure

```text
├── index.html  # download custom browser modpack
└── README.md              # Project documentation
```

## 🎮 How to Play

1. Click on any of the **6 HTML files** listed above in this repository.
2. Click the **Download raw file** button (the down-arrow icon) to save it to your device.
3. Locate the downloaded file on your computer and double-click it.
4. The game will launch immediately inside your default web browser (Chrome, Edge, Firefox, or Safari).

## 🛠️ Contributing & Collaborating

If you are a collaborator working on these 6 modpacks:
1. Make your code adjustments or asset patches directly inside the target HTML file.
2. Commit your updates to the repository.
3. Ensure the file extension remains strictly `.html` to preserve instant-play compatibility.
